## Ograniczenia (zbiorczo)
1. **Figma Embed API:** z `fillmein.local` nie przyszło żadne zdarzenie (origin nie jest zarejestrowany w aplikacji OAuth).
   Aplikacja nie zna bieżącego ekranu prototypu, więc uwagi wiążą się z ekranem wskazanym ręcznie (obraz z API) albo z opisem
   bez pinezki. Interfejs to komunikuje.
2. **Wersja Figmy:** `version` pliku z API identyfikuje wersję pliku, nie ekranu. Bez dostępu API decyzja ma status
   „wersja nieustalona” z jawnym opisem. Link Figmy zawsze pokazuje bieżący stan pliku.
3. **Dostęp do Figmy jest osobny:** link recenzji go nie daje. Prywatny plik pokaże gościowi logowanie Figmy.
4. **Tożsamość gościa** to nazwa deklarowana, niepotwierdzona. Decyzja nie jest podpisem elektronicznym.
5. **Obrazy ekranów** widzi każdy z ważnym linkiem recenzji projektu, niezależnie od uprawnień w Figmie.
6. **E-mail** odroczony. Powiadomienia działają tylko w panelu i obejmują uwagi, odpowiedzi i decyzje (bez zmian statusu).
7. **Brak retencji** powiadomień i danych gości poza usunięciem projektu; polityka retencji to decyzja właściciela.
8. **Logi dostępowe serwera** produkcji mogą zapisywać ścieżki `/p/…` i `/r/…` (Local ich nie zapisuje). Zalecane maskowanie.
9. `inert` w trybie Komentuj działa w Chrome 102+, Safari 15.5+ i Firefox 112+.
