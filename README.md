# Fill Me In

Aplikacja OhSoFresh Creative do zbierania treści od klientów na podstawie projektów w Figmie.
Motyw WordPress oparty o [Sage 11](https://roots.io/sage/) i [Acorn](https://roots.io/acorn/).

- [PROJECT.md](PROJECT.md) — cel, architektura, baza danych, uprawnienia, bezpieczeństwo, roadmapa
- [DEVELOPMENT.md](DEVELOPMENT.md) — uruchomienie lokalne, migracje, build, komendy
- [AGENTS.md](AGENTS.md) — zasady pracy dla agentów AI (Claude Code, Codex, Copilot)
